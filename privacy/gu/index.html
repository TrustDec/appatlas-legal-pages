AppAtlas માટે એકાઉન્ટ જરૂરી નથી અને તમારી શોધ મેળવનાર પોતાનો સર્વર તે ચલાવતું નથી. એપ શોધતી વખતે શોધ શબ્દ, App Store ID અથવા Bundle ID અને પસંદ કરેલો સ્ટોરફ્રન્ટ પરિણામ આપવા માટે તમારા ડિવાઇસમાંથી સીધા Appleની જાહેર શોધ સેવાઓને મોકલાઈ શકે છે. Apple વિનંતી અને સામાન્ય કનેક્શન માહિતી મેળવી શકે છે અને તેને Appleની ગોપનીયતા નીતિ મુજબ સંભાળે છે. AppAtlasના વિકાસકર્તાને આ શોધ મળતી કે સંગ્રહાતી નથી.

મનપસંદ, તાજેતરની શોધ અને સ્નૅપશૉટ, પિન કરેલા સ્ટોરફ્રન્ટ અને પસંદગીઓ ફક્ત તમારા ડિવાઇસમાં સંગ્રહાય છે; AppAtlas સર્વર સાથે સિંક થતી નથી. વૈકલ્પિક સ્થાનિક મોનિટરિંગ જાહેર સ્ટોર માહિતી તપાસવા iOS બૅકગ્રાઉન્ડ રિફ્રેશ વાપરી શકે છે; iOS તેને મોડું કે છોડી શકે છે. સૂચનાઓ સ્થાનિક છે. AppAtlas જાહેરાત, એનાલિટિક્સ અથવા ટ્રેકિંગ SDK વાપરતું નથી. સંપર્ક: kayprivacy@hotmail.com. અમલ તારીખ: ૨૯ સપ્ટેમ્બર ૨૦૨૬.

સહાયAppAtlas એક સ્વતંત્ર એપ છે અને Apple સાથે સંકળાયેલી નથી.
